# Data Analytics Dashboard

A modern, interactive data visualization dashboard built with React, Vite, and Tailwind CSS. Easily upload, analyze, and visualize your data with beautiful charts and a clean UI.

## Features
- Upload and visualize data (supports Excel/CSV)
- Interactive charts using Chart.js
- Drag-and-drop file upload
- Responsive and modern design
- Built with React, Vite, and Tailwind CSS

## Getting Started

### Prerequisites
- Node.js 18.x
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/rk0802p/data_visualization_web.git
cd data_visualization_web

# Install dependencies
npm install --legacy-peer-deps
```

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## Deployment
This project is ready to deploy on [Vercel](https://vercel.com/):
- Push your code to GitHub
- Import the repo on Vercel
- Vercel auto-detects the build settings
